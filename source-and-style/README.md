# Source and Style

## Assignment 1: Inspecting the Cultural Web

For this assignment, I looked at [By the People](https://crowd.loc.gov/), a Library of Congress website where volunteers transcribe and tag historical documents. Its source code is available in the [Concordia GitHub repository](https://github.com/LibraryOfCongress/concordia).

The website uses HTML, CSS, and JavaScript. HTML creates the content and page structure, CSS controls the colors and layout, and JavaScript adds interactive features. The repository also uses Python and Django for the server-side part of the website. Other files, such as `Dockerfile`, `package.json`, and `docker-compose.yml`, help with installing, building, and running the project.

The Library of Congress built By the People. The project was made by a team, not one person: the repository has many contributors and thousands of commits. The Concordia team included people working in technical, product, community-management, and design roles. Volunteers also contribute by transcribing and reviewing documents.

## Assignment 2: Styling the Cultural Web

The `index.html` file presents a photograph of Rosa Parks on a Montgomery bus in 1956. It includes the image, a description, object metadata, and links to the original Library of Congress record and related collections.
